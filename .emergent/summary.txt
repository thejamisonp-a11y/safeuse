The user wants to build a fully functional live demo of a mobile application called **SAFEUSE**.

**SAFEUSE** is a harm-reduction drug interaction checker with a non-judgemental, safety-first philosophy.

**PRODUCT REQUIREMENTS:**
- **Core Functionality:**
  - A drug combination checker for 2-3 substances.
  - A deterministic risk output (LOW, MODERATE, HIGH, AVOID) with color-coding.
  - An Already Taken mode that alters the advice tone.
  - Contextual harm-reduction advice.
  - Symptom-based emergency escalation guidance.
- **Key Principles:**
  - Harm reduction, not encouragement.
  - Calm, factual, non-judgemental language.
  - AI is used ONLY to explain pre-calculated risks, not to decide them.
  - Privacy-first: No accounts, no tracking.
- **Tech Stack:**
  - **Frontend:** Expo + React Native
  - **Backend:** Node.js (FastAPI was used)
  - **AI:** OpenAI API for text explanation.
  - **Data:** Seeded from JSON/in-code (initially), later updated to use authoritative sources like TripSit.me.
- **UI/UX:**
  - Mobile-first, clean, clinical, and calm.
  - Specific screens: Home, Checker, and Result.
